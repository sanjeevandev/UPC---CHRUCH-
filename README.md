# ⛪ United Pentecostal Coastal (UPC Coastal)

A modern, responsive, and cinematic church website built with React, TypeScript, Tailwind CSS, and Framer Motion. Inspired by contemporary church web design with video hero banners, continuous marquees, parallax connect groups, sermon media player, and interactive visitor onboarding.

---

## 🌟 Features
- **Cinematic Video Hero**: Ambient background video with dark gradient tint, high-impact Oswald typography, and dual conversion CTAs.
- **Sticky Frosted Navigation**: Translucent backdrop blur with smooth scroll triggers and full-screen mobile drawer.
- **Infinite Marquee Ticker**: Continuous smooth scrolling announcement banner.
- **3-Column Service Info Grid**: Service Times, Location / Google Maps shortcut, and VIP Plan Your Visit card.
- **Lead Pastor Greeting**: Split 50/50 layout featuring Pastor Rajan Joel and the church mission statement.
- **Parallax Connect Groups**: Full-width parallax image section with interactive group selector.
- **Latest Preaching & Media**: Official YouTube channel (`@UnitedpentecostalchurchBODI`) integration with video modal player.
- **Ministries Showcase**: Dedicated cards for Kids Kingdom, Youth & Young Adults, Worship, and Discipleship.
- **Interactive Prayer Request Section**: Intercession form with confidentiality toggle and direct email connectivity.
- **VIP Plan Your Visit Modal**: Multi-step pre-registration form with kids check-in fast-track and confetti celebration.
- **Interactive Location Modal**: Campus guide with direct [Google Maps GPS integration](https://maps.app.goo.gl/UdonX2UpNLX8pDzf6).
- **Mega Footer**: Gathering schedules, campus address, social media links, and copyright.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v18+)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/sanjeevandev/UPC---CHRUCH-.git

# Navigate to the project directory
cd UPC---CHRUCH-

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build
```bash
npm run build
```

- **Framework**: React 19 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4

- **Icons**: Lucide React
- **Animations & Effects**: Framer Motion, CSS Keyframes & Canvas Confetti
